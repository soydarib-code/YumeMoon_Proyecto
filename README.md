
# Yume Moon Café

Este es mi proyecto de desarrollo web para el curso. Creé una página sobre una cafetería de estilo japonés llamada Yume Moon Café, donde se pueden encontrar bebidas y dulces japoneses.

## Páginas del sitio

- Inicio: presentación de la cafetería.
- Nosotros: información sobre el café.
- Dulces: catálogo de dulces.
- Bebidas: catálogo de bebidas calientes y frías.
- Visítanos: información para visitar la cafetería.

## Tecnologías utilizadas

- HTML5 para la estructura de las páginas.
- CSS3 para los estilos.
- SCSS para organizar mejor el código CSS.
- Bootstrap para algunos componentes y el diseño responsive.
- AOS para agregar animaciones al hacer scroll.

## Organización del proyecto

- index.html: página principal.
- Pages: contiene las páginas internas.
- Assets: logo, íconos e Imagenes.
- Scss: archivos de estilos organizados por secciones.
- Styles: archivo CSS que utiliza la página.

## Accesibilidad

Durante el desarrollo utilicé etiquetas semánticas de HTML como header, nav, main, section y footer.

También agregué textos alternativos en las imágenes para mejorar la accesibilidad y organicé los títulos de las páginas utilizando encabezados HTML.
